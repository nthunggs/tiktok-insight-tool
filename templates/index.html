Có nhiều cookie tên msToken? Chọn cái có: Domain = .tiktok.com (chấm đầu) + Value dài nhất (~150 ký tự).
  1. Mở Chrome/Brave/Edge → tiktok.com → đăng nhập
  2. Nhấn ⌘+⌥+I → DevTools
  3. Tab Application → Storage → Cookies → https://www.tiktok.com
  4. Tìm msToken Domain .tiktok.com → copy Value
  1. Mở Chrome/Edge → tiktok.com → đăng nhập
