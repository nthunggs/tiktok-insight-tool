Cách lấy trên macOS
Chrome / Brave / Edge
  1. Mở tiktok.com → đăng nhập
  2. Nhấn ⌘+⌥+I → mở DevTools
  3. Tab Application (bấm » nếu ẩn)
  4. Sidebar: Cookies → https://www.tiktok.com
  5. Tìm hàng msToken → copy Value
Safari
  1. Settings → Advanced → tick Show Develop menu
  2. Mở tiktok.com → đăng nhập
  3. Develop → Show Web Inspector (⌘⌥I)
  4. Tab Storage → Cookies → tiktok.com
  5. Tìm msToken → copy Value
Token hết hạn sau vài giờ — gặp lỗi auth thì lấy lại token mới.
